  - 프로젝트·활동을 같은 소속·기간·목표를 공유하는 상세 경험의 묶음으로 명확히 정의한다.
  - 중간 구분에 소속, 기간, 공통 목표, 설명 등 프로젝트 공통 메타데이터를 보강한다.
  - AI가 상세 경험을 먼저 추출한 뒤 동일 프로젝트·활동별로 그룹화하도록 개선한다.
  - 기존 프로젝트·활동과 이름·소속·기간·목표를 비교하여 기존 항목 연결을 우선한다.
  - 중간 구분 이름과 상세 카드 제목이 사실상 중복되지 않도록 프롬프트·검증 규칙을 보강한다.
  - 근거가 하나의 사례만 포함하면 프로젝트·활동 아래 상세 카드 1개도 허용하며 억지로 분리하지 않는다.
  - 이번 작업에서는 메모만 남기며 관련 프론트엔드·API·스키마·AI 코드는 수정하지 않는다.
