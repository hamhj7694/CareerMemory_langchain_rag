## 2026-10-27 — 기존 경험 증분 업데이트와 경험 관리 V2 분석 통합

- **상태:** 현재 `dev` 작업 트리의 미커밋 변경. old 직접 분석·제안·저장 API와 기존 데이터 읽기 경로는 유지했다.

- **회귀 수정:** 브라우저 테스트에서 저장 완료 문구가 먼저 렌더링된 순간 닫기 버튼을 누르면 저장 후 목록 새로고침이 끝나기 전 클릭이 무시되는 경쟁 상태를 발견했다. 처리 중 닫기 버튼을 비활성화하고, 모든 단위가 저장된 경우 닫을 때 제안을 다시 `rejected`로 쓰지 않도록 고쳤다.

- **남은 문제:** 자동 업데이트는 잘못된 병합보다 중복 생성을 택하는 보수적 규칙이다. 의미상 같은 경험이어도 분류·프로젝트나 문구가 크게 달라지면 새 경험으로 제안될 수 있으며, 같은 기술이라는 이유만으로 서로 다른 경험을 합치지는 않는다. 외부 모델 의미 분류의 정확도는 별도 사용자 검토가 필요하다.
