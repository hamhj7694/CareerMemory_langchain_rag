# Career Memory 서비스 기술 스택

## 1. 전체 구조

- 프런트엔드: React + Vite
- 백엔드: Python FastAPI
- AI 엔진: LangChain + LangGraph
- RAG: LangChain Retriever + ChromaDB
- 데이터베이스: SQLite + SQLAlchemy ORM
- 실행 파일: PyInstaller 기반 Windows 실행 파일
- AI 제공자: OpenAI 또는 Google Gemini

```text
React/Vite 프런트엔드
        ↓
FastAPI 백엔드
        ↓
CareerMemory AI Engine
        ├─ LangChain Agent
        ├─ LangGraph 메모리
        ├─ 경험 RAG
        ├─ 근거 RAG
        ├─ 경험 구조화 AI
        └─ 채용공고 분석 AI
        ↓
SQLite + ChromaDB
```

## 3. LLM과 임베딩

### OpenAI

- 채팅 모델 기본값: `gpt-4o-mini`
- 임베딩 기본값: `text-embedding-3-small`
- `ChatOpenAI`
- `OpenAIEmbeddings`
- OpenAI Python SDK
- 구조화 출력용 Function Calling / JSON Schema

### Google Gemini

- 채팅 모델 기본값: `gemini-3.5-flash`
- 임베딩 모델 기본값: `gemini-embedding-2`
- `ChatGoogleGenerativeAI`
- `GoogleGenerativeAIEmbeddings`
- Gemini JSON Schema 구조화 출력

`AI_PROVIDER` 환경 변수로 OpenAI와 Gemini를 선택합니다.

## 4. LangChain·Agent·메모리

- `create_agent`: 대화형 커리어 Agent
- LangChain Chat Model
- LangChain `Document`
- LangChain 메시지 객체
- LangChain Retriever
- LangChain Chroma 연동
- 구조화 출력
- 프롬프트 기반 AI 체인
- AI 응답 검증 및 제한적 재요청
- LangGraph `InMemorySaver`: Agent 실행 중 상태 저장

주요 AI 모듈은 `ChatbotAI`, `ExperienceAI`, `JobAnalysisAI`, `AutoIntentClassifier`, `ConversationMemoryManager`, `ExperienceFileAnalysisAI`입니다.

## 5. RAG와 벡터 데이터베이스

이 서비스는 대화와 저장된 경험을 검색해 답변에 반영하는 RAG 구조를 사용합니다.

### 벡터 DB

- ChromaDB
- `langchain-chroma`
- 로컬 디스크 영구 저장
- 사용자별 컬렉션 분리
- 사용자 ID 해시 기반 컬렉션 이름

저장소는 두 개로 분리됩니다.

1. `data/vector_store/jobs`: 확정된 경험과 채용공고 요구사항 매칭
2. `data/vector_store/evidence`: 대화 원문·업로드 파일·원본 근거

### RAG 처리 기능

- 텍스트 청크 분할
- 청크별 시작·종료 위치 저장
- 콘텐츠 해시 저장
- 원본 파일 ID·메시지 ID 연결
- 벡터 검색 Top-K
- 검색 실패 시 키워드 기반 lexical 검색으로 대체

FAISS, Pinecone, Weaviate, Redis Vector Search는 사용하지 않습니다. 기본 벡터 DB는 ChromaDB입니다.

## 6. 데이터베이스

- SQLite
- SQLAlchemy ORM
- 사용자, 로그인 세션, 대화, 메시지, 첨부 파일
- 경험 분류·프로젝트·상세 경험·경험 근거
- 채용공고·요구사항·경험 매칭 결과

Windows 실행 파일에서는 사용자 데이터가 기본적으로 `%LOCALAPPDATA%\CareerMemory\data`에 생성됩니다.

## 7. FastAPI 백엔드

- FastAPI Router
- Pydantic Request/Response Schema
- CORS
- Multipart File Upload
- HTTP 예외 처리와 API 오류 형식 통일
- `StreamingResponse`
- `text/event-stream` 기반 AI 응답 스트리밍
- `/health` 상태 확인 API

주요 API 영역은 인증, 대화, 첨부 파일, 경험 관리, 경험 근거, 경험 초안, 휴지통, 채용공고 분석입니다.

## 8. Pydantic

Pydantic은 FastAPI 요청·응답, 회원가입·로그인, 대화, 경험, 채용공고, AI 구조화 출력의 검증에 사용합니다.

주요 기능은 `BaseModel`, `Field`, `ValidationError`, `field_validator`, `model_validator`입니다.

## 9. 파일 처리와 OCR

지원 파일: TXT, PDF, PNG, JPEG, WebP

- `PyMuPDF`: PDF 텍스트 추출 및 페이지 렌더링
- `Pillow`: 이미지 처리와 전처리
- `pytesseract`: OCR 호출
- Tesseract OCR: 실제 OCR 실행 프로그램
- `python-multipart`: 업로드 파일 파싱

Tesseract OCR은 별도 Windows 프로그램이므로 이미지나 스캔 PDF OCR을 사용하려면 실행 PC에 설치해야 합니다.

## 10. 인증과 보안

- `pwdlib[argon2]`
- Argon2 비밀번호 해싱
- HttpOnly 세션 쿠키
- CSRF 토큰
- 세션 만료 시간
- 사용자별 데이터 접근 제한
- 사용자별 Chroma 컬렉션 분리
- 복구 질문 답변 해싱

현재 구현은 JWT나 OAuth 외부 로그인 방식이 아니라 로컬 세션 쿠키와 CSRF 보호를 사용합니다.
